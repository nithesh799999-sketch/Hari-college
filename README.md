# Hari Arts and Science College — Separate React Pages

## Pages included
1. Home
2. About College
3. Courses
4. Facilities
5. Admissions
6. Exam Results
7. Academic Calendar
8. College Events
9. Placements
10. Online Payment
11. Contact Us
12. Student Login

Each page has its own file inside `src/pages/`. Shared navigation, footer and page heading are in `src/components/`.

## Run the website
1. Install Node.js on your computer.
2. Extract this ZIP and open the `hari-college-separate-pages` folder in VS Code.
3. Open Terminal in VS Code and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite, usually `http://localhost:5173`.

## Important
The result, payment, contact and login forms are front-end demonstrations only. They do not access real student records, send messages, authenticate accounts or collect payments. Connect a secure backend and approved payment provider before publishing. Replace placeholder college contact details and academic dates with verified official information.
